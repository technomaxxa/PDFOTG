# PDFOTG

### Portable Local PDF Toolkit for Windows

PDFOTG is a Windows-first PDF utility designed to perform common PDF and document-processing operations locally on the user's computer.

PDFOTG uses a bundled local processing environment instead of requiring a third-party cloud PDF-processing service for its core operations. The project is designed around portability, local processing, and a simple desktop experience.
